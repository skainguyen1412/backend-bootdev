Junior DevOps không yêu cầu bạn vận hành hệ thống lớn ngay. Họ cần nền tảng đủ chắc để đào tạo tiếp.

Yêu cầu chính từ các JD đã đọc:

- Linux: file, permission, process, service, log, command line.
- Networking cơ bản: TCP/IP, DNS, port, connectivity check.
- Git: branch, merge, repository workflow.
- Scripting cơ bản: Bash hoặc Python. Node.js là lợi thế nhưng chưa thay hoàn toàn hai thứ này.
- Docker: image, container, volume, network, health check.
- Kubernetes/Helm: mức hiểu khái niệm hoặc đã làm lab.
- CI/CD: hiểu build, test, artifact, deploy; từng dùng GitHub Actions/GitLab CI/Jenkins.
- Cloud: biết cơ bản AWS hoặc Azure.
- IaC: từng tiếp xúc Terraform hoặc Ansible.
- Troubleshooting: đọc log, tái hiện lỗi, thu thập thông tin, biết lúc nào cần escalate.
- English: đọc tài liệu, viết báo cáo, trao đổi với team.
- Thái độ: chủ động học, chịu hỏi, viết documentation tốt.

Nice-to-have:

- Prometheus/Grafana/ELK hoặc monitoring tương tự.
- Security cơ bản: secrets, permission, IAM.
- Chứng chỉ AWS/Azure/Kubernetes/Terraform.
- Java/Spring Boot trong một số team.
- GitOps, Argo CD, artifact repository, SonarQube.

So với profile bạn:

- Đã có: Git, GitHub Actions, CI/CD mobile, release production, logging/debugging, Node.js automation, English rất tốt.
- Thiếu chính: Linux sâu, networking, Bash/Python, Docker/Kubernetes, AWS/Azure và Terraform.

Minimum để bắt đầu apply:

1. Docker hóa một Node.js service.
2. GitHub Actions chạy test → build image → deploy.
3. Terraform dựng môi trường AWS/Azure.
4. Thêm Prometheus/Grafana hoặc logging.
5. Viết một runbook và incident RCA.
6. Có README/video chứng minh tự tay làm.

Đạt sáu mục này, junior fit của bạn có thể từ khoảng **3.2/5 lên gần 4/5**. Chứng chỉ không bắt buộc; project chạy được quan trọng hơn.
